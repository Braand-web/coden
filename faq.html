Dois-je savoir coder ?

Vous décrivez votre projet en langage naturel. Coden génère le code et vous permet d’ajuster le résultat dans le Builder.

Comment fonctionnent les crédits ?

Les générations et les modifications consomment des crédits. Votre espace affiche le solde et la consommation. Consulter les tarifs.

Puis-je publier avec le plan Free ?

Oui, sur une adresse Coden. La connexion d’un nouveau domaine personnalisé nécessite un plan payant.

Puis-je récupérer mon code ?

Les plans payants incluent l’export du code pour poursuivre votre projet en dehors de Coden.

Où trouver les informations sur mes données ?

Consultez notre politique de confidentialité et la page sécurité pour connaître les traitements et les protections applicables.
