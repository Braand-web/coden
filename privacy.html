Confidentialité

Vos projets restent vos projets.

Cette page explique quelles données sont nécessaires au fonctionnement de Coden et dans quels cas elles sont transmises aux prestataires qui exécutent le service.

Données collectées

Coden traite les informations de compte, les données d’usage, les prompts, les fichiers et les paramètres nécessaires pour authentifier les utilisateurs, construire les projets, fournir les aperçus et gérer la facturation.

Propriété des projets

Vous conservez vos droits sur les contenus, le code et les applications produits dans votre espace. Vous restez responsable des éléments que vous importez et des droits associés.

Prestataires techniques

Les informations strictement nécessaires peuvent être transmises aux fournisseurs d’hébergement, de modèles, de paiement ou de déploiement utilisés pour exécuter la fonctionnalité demandée. Coden ne vend pas vos données personnelles.

Secrets et surfaces publiques

Les clés privées ne doivent pas être placées dans le frontend généré. Les aperçus privés, le Dashboard et le Builder ne sont pas destinés à l’indexation publique.

Vos demandes

Pour une question, une demande d’accès ou une demande de suppression liée à votre compte, contactez contact@coden.fun.
