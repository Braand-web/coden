Coden

Confidentialité

Vos projets restent vos projets.

Cette page explique quelles données sont nécessaires au fonctionnement de Coden et dans quels cas elles sont transmises aux prestataires qui exécutent le service.

Données collectées

Coden traite les informations de compte, les données d’usage, les prompts, les fichiers et les paramètres nécessaires pour authentifier les utilisateurs, construire les projets, fournir les aperçus et gérer la facturation.

Propriété des projets

Vous conservez vos droits sur les contenus, le code et les applications produits dans votre espace. Vous restez responsable des éléments que vous importez et des droits associés.

Prestataires techniques

Les informations strictement nécessaires peuvent être transmises aux fournisseurs d’hébergement, de modèles, de paiement ou de déploiement utilisés pour exécuter la fonctionnalité demandée. Coden ne vend pas vos données personnelles.

Secrets et surfaces publiques

Les clés privées ne doivent pas être placées dans le frontend généré. Les aperçus privés, le Dashboard et le Builder ne sont pas destinés à l’indexation publique.

Amélioration de l’agent Coden

Les modèles d’IA utilisés par Coden ne sont pas réentraînés avec vos données. Coden améliore sa propre couche d’agent : les corrections d’erreurs qui fonctionnent, les combinaisons de bibliothèques qui passent la vérification et les modèles qui réussissent le mieux chaque type de tâche.

Si l’option « Aider à améliorer l’agent Coden avec mes données » est cochée (Paramètres → Personnalisation), Coden enregistre des signaux de qualité : réussite ou échec d’un build, erreurs corrigées, relances, 👍/👎 et versions restaurées. Avant d’alimenter la base commune, tout est anonymisé : clés d’API, secrets, e-mails, noms, chemins de fichiers, données de bases de données et contenus privés sont retirés, et seuls des schémas techniques génériques sont conservés. Un schéma n’est proposé à d’autres personnes qu’après avoir été observé chez plusieurs utilisateurs.

Décocher l’option prend effet immédiatement : vos données ne sont plus utilisées pour la base commune, et vos contributions passées sont supprimées. Vos instructions personnelles et la mémoire privée apprise de vos projets (stack, langue, style) servent uniquement à vos propres sessions.

Vos demandes

Pour une question, une demande d’accès ou une demande de suppression liée à votre compte, contactez contact@coden.fun.
