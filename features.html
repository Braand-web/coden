Fonctionnalités

Un seul espace pour construire, vérifier et publier.

Coden garde la conversation, les fichiers, l’aperçu, les données et la publication dans le même flux de travail.

01

Un agent qui comprend l’intention

Auto choisit le bon type d’action. Plan clarifie le périmètre. Build modifie les fichiers lorsque la demande est assez précise.

02

Un aperçu qui montre le vrai produit

Inspectez les écrans, les interactions, les états et le responsive pendant la création, puis demandez des corrections ciblées dans la conversation.

03

Une publication sous votre contrôle

Les versions, le rollback, l’export, les domaines et la publication restent séparés du travail en cours jusqu’à votre décision.
