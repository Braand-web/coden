# Connector logos

The SVG files in this folder come from [Simple Icons](https://simpleicons.org)
(package `simple-icons` 16.32.0), released under CC0 1.0 Universal, coloured
with each brand's own colour from the same package.

Every logo is the trademark of its owner. It is shown only to identify the
service a Coden user can connect, in line with each brand's guidelines.
